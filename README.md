# Ihab Diab | Product Manager Portfolio

Static, single-file portfolio site ready for GitHub Pages.

## Publish
1. Open the GitHub repository `ihabad/_portfolio`.
2. Click **Add file → Upload files** and upload `index.html` to the repository root (not inside a folder).
3. Commit your change to the `main` branch.
4. Open **Settings → Pages**.
5. Set **Source:** Deploy from a branch; **Branch:** main; **Folder:** / (root). Save.
6. Check the deployment under **Actions**; after it succeeds, visit https://ihabad.github.io/_portfolio/.

The two healthcare concept briefs are clearly labeled as independent concepts. The Necessary Behavior work is presented separately as professional experience.
